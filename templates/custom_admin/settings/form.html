Setting Guidelines
Key Naming
  • Use UPPERCASE with underscores
  • Be descriptive (e.g., RAZORPAY_KEY_ID)
  • Match .env variable names for consistency
Security
  • Mark API keys and secrets as "Sensitive"
  • All values are encrypted in the database
  • Masked values show as **** in the list view
Categories
  • Email: SMTP and email service settings
  • Payment: Razorpay and payment gateway
  • Google: Google OAuth and services
  • Firebase: FCM push notifications
  • Storage: AWS S3 and file storage
Fallback Behavior

When a setting is inactive, the system automatically falls back to reading from the .env file. This is useful for testing or temporary overrides.
